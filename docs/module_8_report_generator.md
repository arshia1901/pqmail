# Module 8: HTML Report Generator

**Status:** Ready to implement  
**Dependencies:** Modules 1-7 (complete)  
**Libraries:** Jinja2 (templating), pqmail.auditor.batch_scorer

## Overview

Module 8 generates **static HTML reports** summarizing email security risks. Used for:
- Academic paper submissions (formatted report)
- Security audits (compliance documentation)
- Risk dashboards (printable snapshots)

---

## Architecture

```
Input: .mbox mailbox file or email batch
       ↓
[1. Parse & Score]  (reuse Module 5: BatchScorer)
       ↓
[2. Aggregate Risk] (calculate statistics)
       ↓
[3. Render Template] (Jinja2 → HTML)
       ↓
Output: report_YYYY-MM-DD.html (static HTML)
```

### 2.2 Report Data Structure

**ReportData** (passed to Jinja2 template):

```python
@dataclass
class ReportData:
    generated_at: str  # ISO timestamp
    mailbox_path: str
    total_emails: int
    
    # Aggregates
    by_algorithm: Dict[str, int]      # UNENCRYPTED, RSA, ECDH, HYBRID counts
    by_sensitivity: Dict[str, int]    # CRITICAL, HIGH, MEDIUM, LOW
    by_risk_category: Dict[str, int]  # CRITICAL, HIGH, MEDIUM, LOW (risk-based)
    
    # Risk Metrics
    avg_years_of_safety: float
    critical_count: int
    hybrid_count: int
    defense_horizon_total_years: int  # Sum of all defense horizons
    
    # Email samples (top 20 by risk)
    critical_emails: List[Dict]  # [{from, to, algorithm, risk_category, years_of_safety}]
    unencrypted_emails: List[Dict]
    hybrid_emails: List[Dict]
```

### 2.3 HTML Template (pqmail/report/templates/risk_report.html.j2)

**Current Template:** Already exists! Uses Jinja2.

**Sections:**

1. **Header**
   - Title: "PQMail Security Risk Report"
   - Generated date/time
   - Mailbox filename
   - Total emails analyzed

2. **Executive Summary**
   - Risk overview: "X% of emails are CRITICAL"
   - Key metrics: Total unencrypted, hybrid encrypted, quantum-resistant
   - Average years until quantum threat

3. **Algorithm Distribution** (pie/bar chart via CSS or HTML table)
   - UNENCRYPTED: X emails (risk)
   - RSA: Y emails (5-year defense)
   - ECDH: Z emails (7-year defense)
   - HYBRID: W emails (50-year defense)

4. **Risk Breakdown** (by HNDL category)
   - CRITICAL: X emails (0-5 years)
   - HIGH: Y emails (5-10 years)
   - MEDIUM: Z emails (10-20 years)
   - LOW: W emails (20+ years)

5. **Sensitivity Breakdown**
   - CRITICAL sensitivity: X emails (urgent, secret, confidential detected)
   - HIGH: Y emails
   - MEDIUM: Z emails
   - LOW: W emails

6. **Critical Email Examples** (table)
   - From | To | Algorithm | Risk | Years of Safety
   - Top 20 most critical emails for review

7. **Recommendations**
   - "Upgrade X unencrypted emails to hybrid encryption"
   - "Quantum threat timeline: 10 years (configurable)"
   - "Defense horizons: RSA=5yr, ECDH=7yr, HYBRID=50yr"

8. **Footer**
   - Report generated by PQMail
   - Analysis date
   - Compliance notice (if any)

## Usage Example

```python
from pqmail.report.report_generator import ReportGenerator

# Generate report from mailbox
reporter = ReportGenerator("samples/mailbox.mbox", output_dir="reports/")
report_path = await reporter.generate()
print(f"Report saved: {report_path}")
# Output: reports/report_2026-05-18_14-32-45.html
```

## Implementation Steps

1. **Create ReportGenerator class**
   - Import BatchScorer from Module 5
   - Implement `generate()` async method
   - Parse & score mailbox

2. **Calculate aggregates**
   - Count by algorithm, sensitivity, risk category
   - Calculate average years of safety
   - Find top critical emails

3. **Render Jinja2 template**
   - Load `templates/risk_report.html.j2`
   - Pass ReportData to template
   - Render to HTML string

4. **Write to disk**
   - Generate filename: `report_YYYY-MM-DD_HH-MM-SS.html`
   - Save to output directory
   - Return Path object

## Test File (tests/test_report.py)

@pytest.mark.asyncio
async def test_report_generation():
    """Generate report from real mailbox."""
    reporter = ReportGenerator("samples/mailbox.mbox", output_dir="/tmp")
    report_path = await reporter.generate()
    
    assert report_path.exists()
    content = report_path.read_text()
    assert "PQMail Security Risk Report" in content
    assert "54" in content  # 54 emails in samples/mailbox.mbox
    assert "CRITICAL" in content
    assert "UNENCRYPTED" in content

## Features

✅ **Reproducible:** Same mailbox → same report  
✅ **Audit trail:** Timestamp on every report

## Security Considerations

- No plaintext email content in HTML (only metadata)
- No credentials stored in reports
- Timestamps indicate when report was generated
- Each report file is unique (timestamp in filename)
